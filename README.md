# IFC Federation and Model Health Report

A worked demonstration of an ISO 19650-aligned model health workflow, built on
publicly available buildingSMART sample models. Not a product or a tool for reuse.

## Scope
Nine IFC 4.3 containers from the buildingSMART PCERT sample scene are renamed to
ISO 19650 container identifiers, federated, validated against a hand-authored IDS,
checked for clashes, and reported as a two-page model health dashboard.

Survey of the containers as received: [docs/container-register.md](docs/container-register.md)

## Standards and versions
- IFC 4.3.2.0 (IFC4X3_ADD2), ISO 16739-1:2024
- IDS 1.0
- BCF, version as exported by Trimble Connect (to confirm)
- ISO 19650-2:2018 information container naming

## Source data and provenance
Source models are the buildingSMART Sample-Test-Files
repository, IFC 4.3.2.0 (IFC4X3_ADD2) folder. Files are unmodified apart from renaming.
They remain under buildingSMART's terms; the MIT licence here covers the scripts,
IDS and documentation only.
